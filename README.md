# 询价自动化交互 Demo

## 打开方式

直接双击 `index.html`。页面不依赖网络、服务器、字体包或第三方 JavaScript。

也可以带样例参数打开：

- `index.html?sample=0`：五金出口询价
- `index.html?sample=1`：精密加工急单
- `index.html?sample=2`：电气批量采购

## 演示内容

页面展示一条完整的 7 日试点工作流：

1. 读取邮件、PDF 或表单中的客户询价。
2. 提取客户、产品、数量、规格、交期和付款条件。
3. 匹配产品目录并计算批量折扣、报价与预计毛利。
4. 标记价格、图纸、贸易条款、HS 编码等人工复核风险。
5. 生成一份可直接修改的客户回复邮件。

页面上的公司、联系人、产品、价格、成本和交期均为虚构数据，仅用于流程演示。

## 10 分钟演示建议

1. 先说明客户痛点：销售每天在邮件、Excel、图纸和报价单之间反复复制粘贴。
2. 打开第一个样例，指出“原始询价”和“结构化结果”的对应关系。
3. 切换第二个样例，说明急单会触发图纸版本与交期风险。
4. 切换第三个样例，说明批量报价可以同时保留目标价与最低毛利边界。
5. 最后强调：系统只生成草稿和风险提示，正式报价仍由业务人员确认。
